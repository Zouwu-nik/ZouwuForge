# Изменения

## 1.0 — первый публичный выпуск

- 19 инструментов: NVIDIA DLSS 5; генерация (видео по промту, оживить кадр с движением камеры, перенос движения камеры — экспериментально); восстановление (Deblur, Decompression, Restore, Refine Details, Pixel Upscaler, Upscale (Zlikwid), удаление надписей и водяных знаков, Colorization); композитинг (Alpha Gen, Clean Plate, In/Outpaint); свет (Relight, Day to Night, SDR → HDR); Water Simulation.
- Видео по промту: перерисовка, «по контурам», правка по описанию (Edit Anything), замена объекта по маске и образцу.
- Самоустановка движка и моделей в папку программы, докачка при обрывах, выбор моделей по видеокарте.
- Помощник на локальной модели со зрением: «Описать» и «Улучшить» для промтов.
- Длинные куски: проходы внахлёст с плавной склейкой, «запас видеопамяти» для длинных проходов.
- Проба (25 кадров, 544p), очередь заданий, живое превью генерации (по желанию), Sage Attention в один клик.
- Апскейл ×2 по инструментам — включён там, где он нужен; три разрешения (544/720/1088), ориентация из композиции.
- Вывод: новая композиция и/или слой в исходной.
- Подробный лог, автоостановка движка после закрытия AE, настройка файла подкачки в один клик.
