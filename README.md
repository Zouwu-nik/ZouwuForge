# Zouwu Forge

**Бесплатный плагин для After Effects: нейросетевая постобработка видео прямо в композиции.**
Инструменты LTX 2.5 (IC-LoRA) и NVIDIA DLSS 5 работают локально на вашей видеокарте: плагин сам ставит движок
(портативный ComfyUI) и модели, берёт кадры из композиции и возвращает результат новой композицией.

> Независимый проект. Не связан с Lightricks и NVIDIA и не одобрен ими. LTX — товарный знак Lightricks,
> DLSS — товарный знак NVIDIA; названия упоминаются только для описания совместимости.

## Возможности

| Группа | Инструменты |
|---|---|
| **NVIDIA DLSS 5** | Нейрорендер: материалы, кожа, свет, апскейл до 3× |
| **Генерация** | Видео по промту (перерисовка, «по контурам», правка по описанию, замена объекта по образцу) · Оживить кадр + движение камеры · Перенос движения камеры с другого видео |
| **Восстановление** | Deblur · Decompression · Restore · Refine Details · Pixel Upscaler ×2 · Colorization |
| **Композитинг** | Alpha Gen · Clean Plate · In/Outpaint |
| **Свет и цвет** | Relight · Day to Night · SDR → HDR (EXR) |
| **Эффекты** | Water Simulation |

Ещё:
- **Помощник** — локальная модель со зрением (Qwen3-VL через llama.cpp): кнопки «Описать» и «Улучшить» заполняют промты по кадру, можно писать по-русски.
- **Выбор моделей по видеокарте** — поколение (RTX 50 / 40 / 30) и объём видеопамяти определяются сами.
- **Подробный лог и прогресс** по этапам, проверка свободного места, очистка старых генераций.
- Вертикальные, квадратные и горизонтальные композиции, своё разрешение, «проработка деталей» (больше шагов).

## Требования

- Windows 10/11, After Effects 2020 (17.0) или новее.
- Видеокарта NVIDIA RTX, от 8 ГБ видеопамяти (комфортно — 16 ГБ и больше), актуальный драйвер.
- Оперативная память: 32 ГБ, для 16 ГБ видеопамяти — 64 ГБ.
- Место на диске: 25–70 ГБ под модели (зависит от видеокарты и выбранных инструментов) плюс место под секвенции.
- Бесплатный токен [Hugging Face](https://huggingface.co/settings/tokens) (тип Read) — для скачивания моделей.

## Установка

1. Скачайте архив (**Code → Download ZIP** или раздел **Releases**) и распакуйте **целиком** в папку, где программа будет жить,
   например `D:\ZouwuForge`. Движок, модели и результаты ставятся именно туда.
2. Закройте After Effects и запустите `install.bat` из этой папки.
3. Откройте AE → **Окно → Расширения → «Zouwu Forge — Настройки»**, вкладка «Модели»:
   проверьте поколение видеокарты и память, вставьте токен Hugging Face и нажмите **«Установить / докачать»**.
   Загрузка идёт в фоне и докачивается при обрывах.
4. Работайте в **«Zouwu Forge — Инструменты»**.

Удаление — `uninstall.bat` (убирает панель); папку программы с моделями удалите вручную.

Подробная инструкция по каждому инструменту — в [ИНСТРУКЦИЯ.txt](ИНСТРУКЦИЯ.txt).
