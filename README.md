# Zouwu Forge

**Бесплатный плагин для After Effects: нейросетевая постобработка видео прямо в композиции.** LTX-2.5 (IC-LoRA) и NVIDIA DLSS 5 работают локально на вашей видеокарте — плагин сам ставит движок и модели, берёт кадры из композиции и возвращает результат обратно в AE. Без облака, подписок и ручной возни с ComfyUI.

*A free After Effects plugin for AI video post-processing right in your comp: LTX-2.5 IC-LoRA tools and NVIDIA DLSS 5, running locally on your GPU. Self-installing engine and models. Windows + NVIDIA RTX. Interface in Russian.*

## Возможности

| Группа | Инструменты |
|---|---|
| **NVIDIA DLSS 5** | Нейрорендер: материалы, кожа, свет, апскейл до 3×; пресет «минимальное изменение лиц» |
| **Генерация** | Видео по промту (перерисовка, «по контурам», правка по описанию, замена объекта по образцу) · Оживить кадр + движение камеры · Перенос движения камеры с другого видео *(экспериментально)* |
| **Восстановление** | Deblur · Decompression · Restore · Refine Details · Pixel Upscaler ×2 · Upscale (Zlikwid) · Удаление надписей и водяных знаков · Colorization |
| **Композитинг** | Alpha Gen · Clean Plate · In/Outpaint |
| **Свет и цвет** | Relight · Day to Night · SDR → HDR (EXR) |
| **Эффекты** | Water Simulation |

Ещё:
- **Помощник** — локальная модель со зрением (Qwen3-VL): «Описать» и «Улучшить» заполняют промты по кадру, писать можно по-русски.
- **Длинные куски без скачков** — проходы идут внахлёст и плавно склеиваются; есть «запас видеопамяти» для 200–300 кадров одним проходом.
- **Проба** (25 кадров в 544p) и **очередь заданий** по разным композициям.
- **Живое превью** генерации (по желанию), **Sage Attention** в один клик, апскейл ×2 там, где он нужен.
- Результат — новая композиция и/или слой в исходной. Вертикаль, квадрат и горизонталь — из композиции автоматически.

## Как это работает

1. Вы выбираете инструмент и диапазон кадров в окне **«Zouwu Forge — Инструменты»**.
2. Плагин рендерит кадры композиции, отправляет их в локальный движок (портативный ComfyUI, ставится сам) и собирает граф под выбранный инструмент.
3. Готовые кадры возвращаются в After Effects — новой композицией или слоем поверх исходника, ровно на свои кадры.

Всё — движок, модели, результаты — лежит в одной папке, там же, где `install.bat`. Систему (Python, git и т. п.) плагин не трогает.

## Требования

- Windows 10/11, After Effects 2020 (17.0) или новее.
- Видеокарта NVIDIA RTX (30 / 40 / 50), от 8 ГБ видеопамяти, актуальный драйвер.
- Оперативная память от 32 ГБ.
- Место на диске: 25–70 ГБ под модели (зависит от видеокарты и выбранных инструментов) плюс место под секвенции. Лучше SSD.
- Бесплатный токен [Hugging Face](https://huggingface.co/settings/tokens) (тип Read) — для скачивания моделей.

## Установка

1. [**Скачайте ZouwuForge.zip**](https://github.com/Zouwu-nik/ZouwuForge/releases/latest) (раздел Assets) и распакуйте **целиком** в папку, где программа будет жить, например `D:\ZouwuForge`. Движок, модели и результаты ставятся именно туда.
2. Закройте After Effects и запустите `install.bat` из этой папки. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (у скрипта нет цифровой подписи).
3. Откройте AE → **Окно → Расширения → «Zouwu Forge — Настройки»**, вкладка «Модели»: проверьте видеокарту и память, вставьте токен Hugging Face и нажмите **«Установить / докачать»**. Загрузка идёт в фоне и докачивается при обрывах.
4. Работайте в **«Zouwu Forge — Инструменты»**.

Если движок падает с ошибкой «файл подкачки слишком мал» — запустите `pagefile.bat` (или кнопку «Исправить файл подкачки» в плагине) и перезагрузите компьютер.

Удаление — `uninstall.bat` (убирает панели из AE); папку программы с моделями удалите вручную.

Подробно про каждый инструмент — в [INSTRUCTIONS.txt](INSTRUCTIONS.txt).
