Апскейл
Запоминается для каждого инструмента отдельно. По умолчанию включён только там, где нужен.
Больше шагов — мельче проработка (фактура, края, восстановленный фон). Время генерации растёт.
Какие кадры
Рекомендуется не более 121. Это сколько кадров модель генерирует за один проход, а не длина вашей композиции: длинный диапазон делится на проходы такого размера, и на стыке проходов возможен скачок (его сглаживает «Склейка внахлёст»). Больше 121 — можно, генерация будет дольше. Значение округляется по рекомендации разработчиков LTX.
Вывод
Включено оба — и новая композиция, и слой в исходной. Хотя бы один пункт остаётся включённым. Outpaint меняет размер кадра, поэтому для него новая композиция создаётся всегда.
Файл подкачки Windows
Плагин сам выставит файл подкачки 32–64 ГБ на самом быстром диске (NVMe → SSD → HDD). Нужно одно «Да» в окне Windows и перезагрузка.
Очередь
Задания идут по порядку, каждое — в своей композиции. Удачные убираются из списка, с ошибкой — остаются. «Стоп» прерывает текущее и останавливает очередь.
